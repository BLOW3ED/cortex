# Programas sintéticos oficiales

Aquí van los PDFs de los **programas de estudio por unidad de aprendizaje** (programa sintético) de Ingeniería en Inteligencia Artificial, plan 2020. Se publican en el sitio de tu unidad académica (UPIIZ) o en el de ESCOM; también pídelos a tu coordinación académica si no los encuentras.

Nombra cada archivo con el id de la materia de `curriculum/plan-2020.json`:

```
calculo.pdf
programacion.pdf
fundamentos-economicos.pdf
algebra-lineal.pdf
...
```

## Para qué sirven

Claude Code los lee antes de escribir el contenido de una materia, para que las unidades y los temas coincidan con **lo que realmente te evalúan**, no con lo que cualquier libro cubre. Sin el programa, las lecciones llevan `programa_ref: "pendiente"` y `verify_content.py` lo marca como aviso.

Prioridad para arrancar: `programacion`, `calculo`, `matematicas-discretas`, `fundamentos-economicos`.
